01 / 08

Multilingual Legal Q&A with Cross-LLM Refinement

Python PyTorch QLoRA Qwen2.5-3B Flask

Fine-tuned Qwen2.5-3B with QLoRA into 4 language adapters (English, Hindi, Punjabi, Nepali) for Indian legal Q&A. Built retrieval with BGE/LaBSE embeddings and a two-model pipeline where Qwen2.5-7B critiques and refines answers. Added an NLI entailment check to catch factual drift during refinement.

MMVDNet — Video Violence Detection

Python PyTorch VideoMAE Flask

Fight-scene detection on a VideoMAE backbone (Kinetics-pretrained) with multi-clip sampling, achieving 96% accuracy on the RWF-2000 benchmark. Deployed as a Flask app where users can upload a video or paste a YouTube Shorts link for real-time detection.

Code
03 / 08

CPU Scheduling Simulator

Python Streamlit Matplotlib Pandas

An interactive simulator implementing 8 CPU scheduling algorithms including FCFS, SJF, SRTN, Round Robin, LJF, LRTN, and Static/Dynamic Priority. Features CPU and I/O mixed workloads, preemption, context switches, and aging-based starvation prevention. Includes a tick-by-tick scheduling engine with Gantt chart visualization and metrics for waiting time, turnaround time, response time, CPU utilization, and throughput.

Graph Algorithm Visualizer

JavaScript HTML CSS ES6 Modules

An interactive web application to visualize BFS and DFS graph traversal algorithms step by step. PyTorch · Optimization
Second-Order Optimization Methods
A hands-on PyTorch lab exploring curvature, Newton's method, Hessian computation, quasi-Newton optimization, and Hessian-free methods. Demonstrates why second-order optimization converges in few iterations, and why forming the full Hessian becomes impractical for large networks.
Code
PyTorch · Regularization
Regularization Methods in PyTorch
Implementations of L1/L2 regularization, dropout, batch normalization, and data augmentation techniques to combat overfitting in deep feedforward networks. Includes an interactive regularization explorer.

Autoencoders & Variational Autoencoders
Implementation of standard Autoencoder, Denoising Autoencoder, and Variational Autoencoder (VAE) on MNIST. Covers image reconstruction, dimensionality reduction, bottleneck effects, denoising, and new image generation via VAE.
